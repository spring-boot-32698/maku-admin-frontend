## Introduction
- An admin dashboard built with Vue3, TypeScript, Element Plus, Vue Router, Pinia, Axios, i18n, Vite, etc., with a very low barrier to entry.
- Backends that implement the maku-admin APIs: two open-source projects, [maku-boot] and [maku-cloud].
- Documentation: https://maku.net/docs/maku-admin
- Website: https://maku.net

## Installation
Note: use a nodejs LTS version, e.g. [22.x], to keep the project running stably.

```bash
# Clone the project
git clone https://gitee.com/makunet/maku-admin.git

# Enter the project
cd maku-admin

# Install dependencies
npm install

# Run the project
npm run dev

# Build for release
npm run build
```
